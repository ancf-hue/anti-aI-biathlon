## 🎯 Что это

Полноценный **огневой рубеж биатлона** в браузере — без установки, без регистрации, полностью офлайн.

- 🏹 **5 рубежей × 5 выстрелов** — чередование стрельбы **лёжа** и **стоя**
- 🤖 **ИИ-соперник** с тремя уровнями сложности (Любитель / Профи / Чемпион)
- 🌬 **Ветер и баллистика** — нужно брать поправку
- 💨 **Дыхание и пульс** — удержание огня стабилизирует прицел
- 🎙 **Голосовая озвучка (TTS)** на русском языке
- 📱 **Адаптив** — десктоп, планшет, телефон

## 🌐 Что такое «Anti-AI»

Игра разработана, написана и протестирована **вручную человеком**. Ни строчки кода не сгенерировано ChatGPT, Claude, Gemini, Copilot или другими нейросетями. В мире, где 90% нового контента в интернете — синтетика, такие проекты становятся всё ценнее.

> 💙 *Приложение бесплатное. Было и останется.*

## ✨ Особенности

### 🎮 Управление
| Действие | Десктоп | Мобильное |
|---|---|---|
| Прицел | `← → ↑ ↓` | Экранные кнопки |
| Задержать дыхание | Удерживать `ПРОБЕЛ` | Удерживать **ОГОНЬ** |
| Выстрел | Отпустить `ПРОБЕЛ` | Отпустить **ОГОНЬ** |
| Пауза | `P` / `Esc` | Кнопка ⏸ |
| Вкл/выкл звук | `M` | Кнопка ♫ |
| **Осмотр на 360°** | **Перетащить мышью** | **Свайп пальцем** |
| **Зум** | **Колесо мыши** | **Щипок (pinch)** |

### 🔭 Камера на 360°
- Свободное горизонтальное вращение вокруг рубежа
- Вертикальный наклон с защитой от ухода «под землю»
- Зум от 4 до 15 метров
- Автоматическое переключение высоты камеры при смене стойки (лёжа / стоя)
- Прицел исчезает при развороте в тыл — не светится сквозь мишени

### ⚙️ Технологии
- **Three.js 0.163** — 3D-рендеринг
- **WebGL** — аппаратное ускорение графики
- **Web Audio API** — процедурные звуки выстрела, попадания, толпы
- **Web Speech API** — TTS-озвучка событий матча
- **Pointer Events** — универсальная обработка мыши, пальца, пера
- **PWA** — установка на домашний экран, офлайн-режим

### 🧠 Детекция слабого железа
Автоматически снижается:
- количество частиц (дым, искры, снег)
- pixelRatio (до 1×)
- antialiasing
- лимит одновременных источников звука (24 → 12)

Поддерживаются слабые GPU: Mali-4xx, Adreno 3xx/4xx, Intel HD 3xxx/4xxx, SwiftShader.

## 🚀 Запуск

### Способ 1 — GitHub Pages (онлайн)
Откройте `index.html` через GitHub Pages вашего форка или скачайте и положите на любой хостинг статических файлов.

### Способ 2 — Локально
Просто откройте файл в современном браузере:
```bash
# Chrome, Firefox, Safari, Edge — все работают из коробки
open index.html
```

> ⚠️ Не запускайте через `file://` с включённым ES-module-shims в Chrome — лучше через любой локальный сервер:
> ```bash
> python3 -m http.server 8000
> # затем откройте http://localhost:8000
> ```

### Способ 3 — Как PWA
1. Откройте игру в Chrome/Safari
2. Нажмите **«Установить»** в меню браузера (или «На экран Домой» в iOS)
3. Приложение будет работать полностью офлайн

## 🎿 Правила матча

1. **5 рубежей**, на каждом **5 мишеней**
2. Нечётные рубежи — **лёжа** (мелкие мишени, стабильный прицел)
3. Чётные рубежи — **стоя** (крупнее мишени, сильнее раскачивает)
4. **Ветер** меняется перед каждым выстрелом — берите поправку!
5. **ПРОБЕЛ** (или **ОГОНЬ**) удерживается для задержки дыхания — прицел стабилизируется
6. Отпускаете в момент прицеливания — пуля летит с учётом sway, ветра и случайности
7. Если задерживать слишком долго (> 2.4 сек) — начинается дрожь
8. **Чистый рубеж** (5 из 5) — особая озвучка и звук толпы
9. После 5 рубежей — подсчёт очков, при ничьей — **дополнительный рубеж**
